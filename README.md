# ProjetFormationDotNet

## Name
Projet C# .NET avec une interface WPF

## Description
C'est une copie d'un projet que j'ai fait avec une équipe de développeurs dans le cadre d'une POEI.
Cette version dispose d'une interface graphique WPF pour le Front-end et d'une api-REST pour le back-end.

Back-end:
- API-REST en ASP.NET simulant un fonctionnement bancaire.
- Il insère des transactions bancaires dans une base de données SQLServer à partir de fichiers CSV.
- Edit des fichiers XML selon le contenu de la base de données pour les transmettre aux front-end.

Front-end:
- Interface avec XAML et WPF
- Affiche une liste des utilisateurs et permet leur modifications ou l'ajout d'un utilisateur.
